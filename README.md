# Quick Hire

Quick Hire is a local workforce hiring platform that connects employers with skilled workers through a simple and user-friendly web application.

## Features

- User Registration and Login
- Employer and Worker Profiles
- Job Posting and Management
- Worker Listings
- Secure Authentication
- Database Integration using MySQL
- Responsive User Interface

## Tech Stack

### Backend
- Flask
- Python
- SQLAlchemy

### Frontend
- HTML
- CSS
- JavaScript

### Database
- MySQL
